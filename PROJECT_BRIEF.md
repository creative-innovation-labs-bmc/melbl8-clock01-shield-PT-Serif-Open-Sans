# Project brief

## Description

Shield-optimised 3840 x 804 particle clock using locally hosted PT Serif and Open Sans web-brand fonts.

## Build brief

Purpose:
Create a separate production repository based on creative-innovation-labs-bmc/melbl8-clock01-shield.

Requirements:
- Preserve the current visual layout, animation, colours, timing and 3840 x 804 composition.
- Replace serif typography with PT Serif and sans serif typography with Open Sans.
- Host all required font files locally in the repository, with no Google Fonts runtime dependency.
- Match the closest available weights and adjust only font sizing, offsets or tracking required to keep the original visual alignment.
- Preserve the NVIDIA Shield / Enplug performance profile, including 30 fps cap, cached digit point data, pixelDensity(1), and low-allocation particle loops.
- Keep the site noindex, nofollow, noarchive and include robots.txt.
- Keep automatic viewport scaling for mobile browser testing without changing the native 3840 x 804 canvas.
- QC loading, font paths, clock updates, location fallback, mobile scaling and Shield-safe behaviour.

Reference repository:
https://github.com/creative-innovation-labs-bmc/melbl8-clock01-shield
